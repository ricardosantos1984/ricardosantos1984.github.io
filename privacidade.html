Política de Privacidade

Aplicação "n8n Ricardo" · Última atualização: 28/10/2026

O que é esta aplicação

A "n8n Ricardo" é uma aplicação de uso exclusivamente pessoal. Liga a conta Google do próprio autor, Ricardo Santos, a uma instalação privada do n8n que corre no seu computador, para automatizar tarefas na sua caixa de correio.

Que dados são usados

  • Mensagens e etiquetas do Gmail do próprio autor, para organizar emails por pastas e enviar notificações para si mesmo.
  • Não são acedidas contas de outras pessoas.

Como os dados são tratados

  • Os dados são processados apenas no computador do autor, pela sua instalação do n8n.
  • Não são vendidos, partilhados nem transferidos para terceiros.
  • Não são usados para publicidade.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contacto

Para questões sobre esta política, contacte o autor através do perfil github.com/ricardosantos1984.
